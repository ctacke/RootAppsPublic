# Node-ROOT Python Bot

A lightweight, zero-dependency Python bot for Node-ROOT.

## Files
- `main.py` - Default entrypoint (`python main.py`).
- `bot.py` - Bot handler definitions and command logic (`!ping`, `!echo`).
- `noderoot_bot.py` - Zero-dependency Node-ROOT bot runtime (HMAC verification, event dispatcher, response builder).
- `requirements.txt` - Empty dependency file (uses Python standard library only).

## Deploying to bot-hosting.net

1. **Upload Archive:**
   - In your bot-hosting.net server dashboard, go to **File Manager**.
   - Upload `noderoot-python-bot.zip` and extract its contents into the root directory of the container.
   - Make sure `main.py`, `bot.py`, `noderoot_bot.py`, and `requirements.txt` are in the container's root.

2. **Environment Variables:**
   - Set `NODEROOT_SECRET`: The shared secret generated by Node-ROOT when you add the bot in the community editor.
   - `PORT` / `SERVER_PORT`: Bot-hosting.net assigns this automatically. The bot automatically listens on this port.

3. **Startup:**
   - Verify the Startup command is `python main.py` or `python bot.py`.
   - Start the server and check the console logs to confirm it starts listening.

4. **URL Configuration in Node-ROOT:**
   - Because Node-ROOT requires HTTPS for external webhooks:
     - Use bot-hosting.net's reverse proxy domain (`https://<server-id>.site.bot-hosting.cloud` or custom domain configured via Cloudflare).
     - Enter your HTTPS URL in Node-ROOT under **Bots** -> **Add Bot**.
