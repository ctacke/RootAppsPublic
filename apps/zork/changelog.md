### v1.0.0 — August 14, 2026

*Initial Release of the Zork Trilogy on Root.*

- **The Complete Trilogy**: Full support for *Zork I: The Great Underground Empire*, *Zork II: The Wizard of Frobozz*, and *Zork III: The Dungeon Master*.
- **Pure Z-Machine Interpreter**: Built-in TypeScript Z-code v3 interpreter with high-fidelity Infocom opcode execution, dictionary tokenization, and random number generator seeding.
- **Retro Phosphor Green CRT Console**: Authentic vintage terminal interface featuring scanline effects, phosphor glow, monospace typography, and a classic reverse-video top status line.
- **Continuous Auto-Saving**: Automatic SQLite snapshot saving after every turn, allowing seamless resumption of adventures.
- **Save Slot Manager**: In-app named save checkpoints with location, score, and turn tracking.
- **In-App Styled Modals**: Fully themed in-app dialogs for save management, guide reference, and action confirmations.
- **Command History**: Terminal command buffer with Up/Down arrow key recall.
