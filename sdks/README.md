# Node-ROOT Bot SDKs

Official libraries for writing self-hosted bots and external webhook services for **Node-ROOT** on [Root](https://www.root.io/).

---

## Available SDKs

| SDK | Language | Description | Directory |
| :--- | :--- | :--- | :--- |
| **[@noderoot/bot-sdk](./typescript/)** | TypeScript / Node.js | Zero-dependency TypeScript SDK with standalone server & Express middleware. | [`sdks/typescript/`](./typescript/) |
| **[noderoot-bot](./python/)** | Python 3.9+ | Zero-dependency Python SDK with built-in HTTP server ready for hosts like bot-hosting.net. | [`sdks/python/`](./python/) |

---

## Documentation & Guides

For complete instructions on installing bots, configuring webhooks, HMAC secrets, test events, and delivery monitoring, see the **[Self-Hosted Bots Guide](https://ctacke.github.io/RootAppsPublic/noderoot/bots/)**.
